# Authentication Page

A responsive and interactive login and registration interface built using **HTML5**, **CSS3**, and vanilla **JavaScript**.

## Features
* Clean and modern UI design.
* Toggle functionality between Login and Sign-Up forms.
* Client-side form validation (checks for empty fields, valid email format, and password matching).
* Show/Hide password toggle capability.
* Fully responsive layout for mobile and desktop screens.

## File Structure
```text
├── index.html       # Main HTML structure for authentication
├── style.css        # Stylesheet for layout, colors, and responsiveness
├── script.js        # JavaScript logic for validation and UI toggling
└── README.md        # Project documentation
```

## Getting Started

### Prerequisites
You only need a standard web browser (like Chrome, Firefox, or Edge) to run this project.

### Installation & Running
1. Clone or download this repository to your local machine.
2. Navigate to the project folder.
3. Double-click `index.html` or open it using your preferred web browser.

## Usage
* Enter your details in the **Sign Up** tab to register, or switch to **Log In** if you already have an account.
* Watch for real-time validation error prompts if fields are missing or filled out incorrectly.
